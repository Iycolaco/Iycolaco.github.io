Intro to Vim

Getting There

Obviously the first step is entering the terminal. On a MacBook you can do Cmd + Space to open a search bar where you can type Terminal Now that you are in the terminal the comands that you need to type to enter vim are: 


            cd Desktop/website
            mkdir practice
            vim index.html
Now click Esc+I and at the bottom of the screen you will see -- INSERT -- . Now type: 
               
  1.  <!DOCTYPE html>
    2. 
           
  2.  <html lang="en">
    3. 

            
  3.          <head>
    4. 
                
  4.             <title>Hello World!</title>
    5. 
            
  5.          </head>
    6. 

            
  6.          <body>
    7. 
               
  7.               <h1>Hello, World!</h1>
    8. 
                
  8.              <p>My first html page.</p>
    9. 
            
  9.          </body>
    10. 

            
  10.  </html>
    11.
So far all of these have been block elements. Some inline elements include
  • bold with <strong>
  • itatics with <em>
  • underline with <u>
  • and strike through with <del>
